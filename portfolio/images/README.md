# Portfolio görselleri

Bu klasöre ekran görüntülerini şu isimlerle koy. `index.html` otomatik kullanır.

| Dosya | Ne olmalı |
|-------|-----------|
| `hero.png` | Tam genişlik hero (koleksiyon veya app shell) |
| `grid.png` | Ana kart grid görünümü |
| `search.png` | TMDB arama / ekleme drawer |
| `mobile.png` | Telefon / dar ekran |
| `rankings.png` | Favori sıralama |
| `settings.png` | Ayarlar + GitHub yedek |
| `dev-panel.png` | Electron Dev Panel |

## İpuçları

- Tercihen **PNG**, yatay: ~1600px, mobil: ~900×1600
- Kişisel not / API key görünmesin
- Windows: Win+Shift+S veya tarayıcı DevTools device mode

Sayfayı açmak için `portfolio/index.html` dosyasına çift tıkla veya Live Server kullan.
